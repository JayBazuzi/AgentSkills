# AgentSkills

A personal collection of Claude Code skills, reusable across projects.

## Usage

Symlink or copy individual skill folders into a project's `.claude/skills/` directory,
or symlink this whole repo's `skills/` contents into `~/.claude/skills` to make them
available everywhere.

## Adding a skill

Use the `skill-creator` skill to scaffold and refine new skills under `skills/`.
