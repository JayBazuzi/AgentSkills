# AgentSkills

A personal collection of Claude Code skills, reusable across projects.

## Usage

Skills live in `.claude/skills/`, so they apply automatically to this repo.

To use them elsewhere, symlink or copy individual skill folders into another project's `.claude/skills/` directory, or symlink this repo's `.claude/skills/` contents into `~/.claude/skills` to make them available everywhere.

See [Skills and Scripts](docs/skills-and-scripts.md) for what each term means here and when to use which.
